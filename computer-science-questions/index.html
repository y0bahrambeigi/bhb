سوال ۸ عملگرهای تقسیم در پایتون

تفاوت عملگر / و // چیست؟

عملگر / تقسیم اعشاری را انجام می‌دهد و همیشه خروجی از نوع اعشاری (Float) برمی‌گرداند. اما عملگر // تقسیم صحیح (Floor Division) انجام داده و نتیجه را به سمت پایین گرد می‌کند.

عملگر / (Float Division)
7 / 2 ➔ 3.5

خروجی همراه با اعشار دقیق است.

عملگر // (Floor Division)
7 // 2 ➔ 3

خروجی بخش صحیح گردشده به پایین است.
