# چارچوب علمی BMPOA-FF-SG-DLS برای بهینه‌سازی گسسته خرپاهای فولادی

## هدف پژوهش

این توسعه بررسی می‌کند که آیا هدایت جست‌وجوی محلی گسسته با اطلاعات حساسیت سازه‌ای، تحت بودجه برابر **ارزیابی طرح**، نسبت به BMPOA پایه و جست‌وجوی محلی تصادفی عملکرد بهتری ایجاد می‌کند یا خیر.

مقایسه اصلی شامل سه نسخه است:

1. `BMPOA-FF-core`
2. `BMPOA-FF-RandomDiscreteLS`
3. `BMPOA-FF-SGDLS`

## مدیریت قیود

تابع هدف اصلی فقط وزن سازه است:

[
min W(mathbf{x})
]

و دیگر از تابع جریمه‌ای مانند

[
W+alpha P
]

برای رتبه‌بندی جواب‌ها استفاده نمی‌شود.

تمام قیود به فرم بی‌بُعد

[
g_c(mathbf{x})le 0
]

تبدیل می‌شوند. شدت نقض هر قید:

[
v_c=max(0,g_c)
]

و برای هر خانواده قید:

[
V_k=
left[
rac{1}{N_k}
sum_{c=1}^{N_k}v_c^p
ight]^{1/p}.
]

معیار کلی نقض:

[
V_p=
left[
sum_k eta_k V_k^p
ight]^{1/p}
]

است. مقدار پایه `p=4` بوده و باید بعداً با `p={2,4,8}` تحلیل حساسیت شود.

قانون مقایسه:

- جواب مجاز بر نامجاز مقدم است.
- میان دو جواب مجاز، وزن کمتر بهتر است.
- میان دو جواب نامجاز، ابتدا `Vp` کمتر، سپس `Vinf` کمتر و در نهایت وزن کمتر برتری دارد.

## قید فشار در خرپای 120 عضوی

در مدل 120 عضوی، ظرفیت فشاری تابع لاغری و در نتیجه تابع سطح مقطع است. برای

[
R_i=rac{|sigma_i|}{F_{a,i}(A_i)}
]

مشتق کامل شامل هر دو سهم تغییر تنش و تغییر ظرفیت مجاز فشاری است. بنابراین اثر مستقیم تغییر سطح مقطع بر مقاومت فشاری در SG-DLS حذف نشده است.

[

حساسیت فقط برای **رتبه‌بندی** استفاده می‌شود. پذیرش نهایی هر حرکت الزاماً پس از اجرای واقعی `problem.evaluate()` و قانون `isBetter()` انجام می‌شود.

## حسابداری محاسباتی

بودجه اصلی آزمایش:

[
FE_{max}=35070
]

evaluator call برای هر run است. تمام کاندیدهای BMPOA، RandomDiscreteLS و SG-DLS از همین بودجه مصرف می‌کنند.

از آنجا که SG-DLS محاسبات حساسیت اضافه دارد، موارد زیر جداگانه گزارش می‌شوند:

- sensitivity calls
- static sensitivity RHS
- modal sensitivity solves
- elapsed wall-clock time

بنابراین عبارت علمی صحیح **equal design-evaluation budget** است، نه لزوماً equal computational cost.

## پروتکل آزمایش

آزمون اصلی:

- benchmarkها: 72-bar و 120-bar
- seeds: 2026 تا 2030
- جمعیت: 70
- evaluator budget: 35,070
- restart: خاموش
- QIO: خاموش
- p=4
- حداکثر سه کاندید دقیق SG-DLS در هر مرحله

در مجموع:

[
2	imes3	imes5=30
]

run کنترل‌شده اجرا می‌شود.

## علت حذف QIO از این مرحله

QIO فعلی مخزن رأس سهمی را بر اساس fitness اسکالر جریمه‌ای می‌سازد. واردکردن همزمان QIO جدید و constraint handling جدید باعث اختلاط اثر دو مداخله می‌شود. بنابراین QIO باید در مطالعه حذف مؤلفه جداگانه و با merit function مشخص بررسی شود.

## معیار موفقیت

SG-DLS تنها زمانی به‌عنوان بهبود روش‌شناختی تلقی می‌شود که نسبت به RandomDiscreteLS در بودجه evaluator برابر، به‌صورت پایدار یکی یا چند مورد زیر را بهبود دهد:

- FE تا اولین جواب مجاز
- نرخ feasibility
- میانه وزن نهایی جواب‌های مجاز
- نرخ پذیرش local search
- anytime performance

همزمان باید سربار زمانی حساسیت نیز گزارش شود.
