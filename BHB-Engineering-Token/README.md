# BHB Engineering Token (BHB)

[![BHB Token CI](https://github.com/y0bahrambeigi/bhb/actions/workflows/bhb-engineering-token-ci.yml/badge.svg)](https://github.com/y0bahrambeigi/bhb/actions/workflows/bhb-engineering-token-ci.yml)

بسته اجرایی یک توکن استاندارد ERC-20 و داشبورد مدیریتی برای شبکه آزمایشی Ethereum Sepolia، طراحی و توسعه‌یافته برای کاربردهای آموزشی، پژوهشی و مهندسی.

**طراح و توسعه‌دهنده:** یوسف بهرام بیگی (Yousef Bahram Beigi)

> این پروژه یک توکن روی اتریوم است، نه یک بلاک‌چین مستقل. BHB در نسخه حاضر فقط برای Sepolia طراحی شده و ارزش پولی واقعی ندارد.

## مشخصات توکن

| ویژگی | مقدار |
|---|---:|
| نام | BHB Engineering Token |
| نماد | BHB |
| استاندارد | ERC-20 |
| اعشار | 18 |
| عرضه اولیه | 100,000,000 BHB |
| امکان صدور بعدی | حداکثر 20,000,000 BHB |
| سقف قطعی | 120,000,000 BHB |
| شبکه هدف | Ethereum Sepolia |
| توقف اضطراری | دارد؛ فقط مالک |
| انتقال مالکیت | دومرحله‌ای |
| داشبورد وب | واکنش‌گرا، فارسی و قابل نصب |

صدور بعدی به‌صورت **تجمعی** محدود است. سوزاندن توکن، سهمیه صدور را دوباره باز نمی‌کند. بنابراین مالک در کل عمر قرارداد بیش از ۲۰ میلیون BHB اضافی صادر نخواهد کرد.

## طراحی امنیتی

- استفاده از OpenZeppelin Contracts 5.6.1؛
- سقف غیرقابل‌تغییر در کد قرارداد؛
- توقف اضطراری انتقال، صدور و سوزاندن؛
- صدور فقط توسط مالک و فقط در محدوده سهمیه باقی‌مانده؛
- انتقال مالکیت دومرحله‌ای برای کاهش خطر انتقال اشتباه؛
- جلوگیری از صرف‌نظرکردن مالک از مالکیت در حالت توقف، برای پیشگیری از قفل دائمی؛
- بدون مالیات انتقال، فهرست سیاه، در پشتی، ارتقاپذیری یا امکان افزایش سقف.

## انتشار امن روی Sepolia

### ۱. کیف پول آزمایشی

یک کیف پول جداگانه فقط برای Sepolia بسازید و مقداری Sepolia ETH از یک faucet معتبر دریافت کنید. هرگز عبارت بازیابی یا کلید خصوصی را در چت، GitHub یا فایل `.env` قرار ندهید.

### ۲. ذخیره رمزگذاری‌شده تنظیمات

```bash
npx hardhat keystore set SEPOLIA_RPC_URL
npx hardhat keystore set SEPOLIA_PRIVATE_KEY
```

برای تأیید کد در Etherscan:

```bash
npx hardhat keystore set ETHERSCAN_API_KEY
```

### ۳. انتشار و تأیید

```bash
npm run deploy:sepolia
npm run verify:sepolia
npm run sync:sepolia
```

Hardhat Ignition آدرس قرارداد را پس از انتشار نمایش می‌دهد. فرمان `sync:sepolia` همان آدرس را از نتیجه رسمی انتشار استخراج و در داشبورد ثبت می‌کند.

راهنمای کامل در [docs/DEPLOYMENT_FA.md](docs/DEPLOYMENT_FA.md)، دستورالعمل بهره‌برداری در [docs/OPERATIONS_FA.md](docs/OPERATIONS_FA.md)، گزارش شفافیت در [docs/TRANSPARENCY_FA.md](docs/TRANSPARENCY_FA.md)، نقشه راه در [docs/ROADMAP_FA.md](docs/ROADMAP_FA.md) و نتیجه اعتبارسنجی واقعی در [VALIDATION.md](VALIDATION.md) قرار دارد.

## عملیات مدیریتی مهم

مقادیر توکن در قرارداد ۱۸ رقم اعشار دارند. برای نمونه، صدور ۵۰۰ BHB برابر `500 × 10^18` واحد پایه است.

- `mint(recipient, amount)`: صدور محدود توسط مالک؛
- `pause()`: توقف انتقال، صدور و سوزاندن؛
- `unpause()`: بازگشایی عملیات؛
- `transferOwnership(newOwner)`: شروع انتقال مالکیت؛
- `acceptOwnership()`: پذیرش مالکیت توسط مالک جدید؛
- `remainingMintAllowance()`: سهمیه باقی‌مانده صدور؛
- `burn(amount)`: سوزاندن توکن توسط دارنده.

## آزمون‌های موجود

مجموعه هشت‌گانه آزمون، هویت و عرضه اولیه، انتقال ERC-20، محدودیت دسترسی صدور، سقف تجمعی ۲۰ میلیون، عدم بازگشت سهمیه پس از سوزاندن، توقف اضطراری، انتقال مالکیت دومرحله‌ای و جلوگیری از قفل دائمی هنگام صرف‌نظرکردن از مالکیت را پوشش می‌دهد. گردش CI نیز در `.github/workflows/contract-ci.yml` قرار دارد.
