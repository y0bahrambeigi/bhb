# نقشه راه BHB Engineering Token

این نقشه راه تعهد مالی یا وعده قیمت نیست. عبور از هر مرحله به شواهد فنی، امنیتی و حقوقی وابسته است.

## مرحله ۰ — پایه عمومی

- [x] قرارداد ERC-20 با عرضه اولیه و سقف صدور محدود؛
- [x] توقف اضطراری، سوزاندن و مالکیت دومرحله‌ای؛
- [x] آزمون‌های خودکار، پوشش کد و CI؛
- [x] داشبورد فارسی Sepolia و مستندات اجرایی؛
- [ ] بازبینی عمومی Pull Request و تثبیت نسخه 1.1.0.

## مرحله ۱ — اعتبارسنجی Sepolia

- [ ] استقرار با کیف پول آزمایشی مستقل؛
- [ ] تأیید کد منبع در Sepolia Etherscan؛
- [ ] ثبت آدرس قرارداد در `dashboard/deployment.json`؛
- [ ] اجرای سناریوی انتقال، صدور محدود، توقف و بازگشایی؛
- [ ] انتقال مالکیت آزمایشی به Safe چندامضایی و مستندسازی امضاکنندگان/حدنصاب.

## مرحله ۲ — اعتماد و حاکمیت

- [ ] انتشار لایت‌پیپر و سیاست تخصیص توکن؛
- [ ] تعیین سیاست صدور ۲۰ میلیون واحد تکمیلی؛
- [ ] ممیزی امنیتی مستقل و انتشار پاسخ به یافته‌ها؛
- [ ] برنامه پاسخ به رخداد و اطلاع‌رسانی توقف اضطراری؛
- [ ] بررسی حقوقی مستقل پیش از هر معرفی مالی یا عرضه عمومی.

## مرحله ۳ — پایلوت کاربردی

- [ ] تعریف یک کاربرد قابل‌اندازه‌گیری برای جامعه مهندسی؛
- [ ] جذب گروه آزمایشی محدود در Sepolia؛
- [ ] اندازه‌گیری کاربران فعال، تراکنش موفق، ماندگاری و بازخورد؛
- [ ] انتشار گزارش پایلوت شامل نتایج مثبت و منفی.

## دروازه تصمیم Mainnet

تصمیم درباره Mainnet فقط پس از ممیزی مستقل، شفافیت تخصیص، کنترل چندامضایی، پایلوت موفق و نظر حقوقی مکتوب بررسی می‌شود. تا آن زمان BHB دارایی آزمایشی بدون ارزش پولی است.
