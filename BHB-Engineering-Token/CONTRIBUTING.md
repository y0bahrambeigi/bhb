# مشارکت در BHB Engineering Token

از گزارش خطا، پیشنهاد مستند و Pull Request کوچک و قابل‌آزمون استقبال می‌شود. این پروژه در مرحله آزمایشی Sepolia است و نباید به‌عنوان محصول سرمایه‌گذاری یا دارایی دارای ارزش تضمین‌شده معرفی شود.

## راه‌اندازی محیط توسعه

پیش‌نیاز: Node.js نسخه 22.13 یا جدیدتر.

```bash
npm ci
npm run build
npm run typecheck
npm test
```

برای تغییرات قرارداد، آزمونی اضافه کنید که هم رفتار موفق و هم شکست مورد انتظار را پوشش دهد. برای تغییرات داشبورد، اتصال به Sepolia، حالت بدون کیف پول و نمایش موبایل را بررسی کنید.

## استاندارد Pull Request

- هدف تغییر و دلیل آن را روشن بنویسید؛
- تغییرات نامرتبط را در یک Pull Request ترکیب نکنید؛
- نتیجه آزمون‌ها و اثر امنیتی تغییر را ذکر کنید؛
- هیچ کلید خصوصی، عبارت بازیابی، توکن API، آدرس شخصی یا داده محرمانه ثبت نکنید؛
- درباره سود، قیمت یا بازده آینده ادعای تبلیغاتی مطرح نکنید.

## گزارش امنیتی

آسیب‌پذیری را در Issue عمومی منتشر نکنید. روش ارتباط امن و دامنه پشتیبانی در [SECURITY.md](SECURITY.md) توضیح داده شده است.

با ارسال مشارکت، می‌پذیرید که تغییرات تحت مجوز MIT پروژه منتشر شوند.
