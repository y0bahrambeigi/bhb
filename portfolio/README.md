# Yousef Bahrambeigi — Professional Portfolio

Persian structural-engineering and research portfolio, with an English introduction, project pages, publications, printable resume, and structured metadata.

Live GitHub Pages URL: https://y0bahrambeigi.github.io/bhb/portfolio/

Original Sites publication: https://yousef-bahrambeigi.yousefbhb.chatgpt.site

## Update content

Edit `build-source.py`, then run `python3 portfolio/build-source.py` from the repository root. CSS and assets are maintained directly in this directory. No package installation is needed.

GitHub Pages must serve the repository root. All existing repository applications are preserved. The sitemap is `portfolio/sitemap.xml`; the robots.txt in this subdirectory is informational, since crawlers use the hostname-root robots.txt.

Information sources and verification notes are on the Sources page. Google Scholar is omitted until the profile URL is verified.
