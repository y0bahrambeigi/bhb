# MohandesYar AI Installer Hub

مرکز نصب فارسی و واکنش‌گرای «مهندس‌یار AI» برای راه‌اندازی نسخه PWA در ویندوز، آیفون، آیپد، اندروید و مرورگر وب.

## امکانات

- تشخیص خودکار دستگاه و سیستم‌عامل
- بررسی اتصال اینترنت، HTTPS، ذخیره‌سازی محلی و پشتیبانی PWA
- راهنمای نصب اختصاصی برای هر پلتفرم
- اجرای مستقیم نسخه رسمی مهندس‌یار AI
- کپی سریع لینک نصب
- رابط RTL سازگار با موبایل و دسکتاپ
