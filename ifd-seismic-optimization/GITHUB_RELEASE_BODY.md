## IFD Seismic Optimization Framework v1.0.0-rc1

First release candidate of the source-constrained IFD seismic-optimization framework.

### Included
- MATLAB MDOF + provisional IFD solver
- robust multi-record evaluation and scaling
- dissertation BMPOA adapter and equal-FE runner
- independent Python QA reference
- reproducibility gates and provenance matrix
- preprint manuscript source
- CITATION.cff, license, and archive metadata

### Validation boundary
This release verifies the computational framework but **does not claim exact reproduction of Hu et al. (2026)**. Exact source equations, specimen data, reference curves, and Rp definition remain pending.
