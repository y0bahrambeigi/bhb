## When to cite which object?

- **Used the software in a study/workflow?** Cite the software DOI above.
- **Discussing architecture, design rationale, validation, or documented methods?** Cite the technical report where relevant: DOI 10.6084/m9.figshare.33935692.v2.
- **After a peer-reviewed SoftwareX paper is published:** cite that paper when the scholarly discussion depends on the paper, and cite the software DOI as well when reproducibility requires identifying the exact software version.

Do not add citations solely to increase citation counts. A citation should document a genuine intellectual, methodological, or software dependency.
