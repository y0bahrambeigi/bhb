# مهندس‌یار AI — نسخه ۲.۰.۰

مهندس‌یار AI یک نرم‌افزار وب پیش‌رونده (PWA) آفلاین‌محور برای تشکیل پرونده پروژه، ثبت واقعی شواهد میدانی و تولید گزارش فارسی پروژه‌های عمرانی است.

نسخه عمومی پس از انتشار در این نشانی در دسترس خواهد بود:

<https://y0bahrambeigi.github.io/bhb/mohandesyar-ai/>

## امکانات عملیاتی

- ایجاد، ویرایش، انتخاب و حذف چند پرونده پروژه
- ذخیره فایل اصلی عکس و ویدئو در IndexedDB دستگاه
- ثبت نام، نوع، حجم، زمان و هش SHA-256 هر مدرک
- ثبت اختیاری مختصات GPS و دقت موقعیت با اجازه کاربر
- پیش‌نمایش، دریافت و حذف مستقل هر مدرک
- تولید گزارش فارسی از اطلاعات واقعی پرونده و شواهد همان پرونده
- درج تصویر، زمان، GPS و هش مدرک در نسخه چاپی
- چاپ یا ذخیره PDF با قالب A4 و واترمارک وضعیت گزارش
- پشتیبان‌گیری JSON شامل پرونده‌ها و فایل‌های شواهد و بازیابی آن
- نصب روی موبایل و رایانه و اجرای آفلاین پس از نخستین بارگذاری موفق
- مهاجرت ایمن مشخصات باقی‌مانده از نسخه نمایشی قدیمی

## حریم خصوصی و مدل ذخیره‌سازی

داده‌ها به GitHub یا سرور دیگری ارسال نمی‌شوند. پرونده‌ها و فایل‌ها در IndexedDB همان origin مرورگر ذخیره می‌شوند. پاک‌کردن داده‌های سایت، حذف مرورگر یا بازنشانی دستگاه می‌تواند این اطلاعات را حذف کند؛ پس از هر بازدید مهم یک فایل پشتیبان تهیه کنید.

GPS فقط در صورتی خوانده می‌شود که گزینه «ثبت موقعیت GPS همراه مدرک» فعال باشد و کاربر مجوز مرورگر را تأیید کند.

حداکثر حجم هر فایل در نسخه فعلی ۱۰۰ مگابایت است. ظرفیت کل به سهمیه مرورگر و فضای آزاد دستگاه وابسته است.

## نصب

### Android / Chrome

1. نشانی برنامه را در Chrome باز کنید.
2. دکمه «نصب برنامه» یا گزینه **Install app / Add to Home screen** را انتخاب کنید.
3. برنامه را یک‌بار در حالت آنلاین باز کنید تا وضعیت «نسخه آفلاین آماده است» نمایش داده شود.

### iPhone / Safari

1. برنامه را در Safari باز کنید.
2. از منوی Share گزینه **Add to Home Screen** را انتخاب کنید.
3. برنامه افزوده‌شده را یک‌بار آنلاین اجرا کنید.

### رایانه

در Chrome یا Edge از دکمه نصب نوار نشانی یا دکمه «نصب برنامه» استفاده کنید.

## پشتیبان‌گیری و بازیابی

- «دریافت پشتیبان» یک فایل JSON شامل اطلاعات و محتوای فایل‌های شواهد ایجاد می‌کند.
- برای بازیابی، فایل را از بخش «بازیابی پشتیبان» انتخاب کنید.
- حالت جایگزین همه داده‌های موجود را پاک می‌کند و فقط پس از تأیید کاربر اجرا می‌شود.
- چون فایل‌های تصویری و ویدئویی داخل پشتیبان قرار می‌گیرند، حجم فایل JSON می‌تواند زیاد باشد.

## گزارش و PDF

گزارش از پرونده فعال و شواهد ذخیره‌شده همان پرونده تولید می‌شود. وضعیت «پیش‌نویس»، «نیازمند بازبینی» یا «تأییدشده» به‌صورت واترمارک چاپ می‌شود. گزینه چاپ از گفت‌وگوی بومی مرورگر برای ذخیره PDF استفاده می‌کند.

تأییدشده‌بودن در نرم‌افزار جایگزین کنترل حرفه‌ای، مهر، امضا، شماره دبیرخانه یا الزامات مرجع قانونی نیست.

## محدودیت‌های نسخه ۲.۰.۰

- نسخه GitHub Pages تک‌کاربره و محلی است و همگام‌سازی ابری ندارد.
- ورود کاربر، نقش سازمانی و امضای دیجیتال سمت سرور وجود ندارد.
- عبارت AI نام محصول است؛ این نسخه عمومی هیچ داده‌ای را برای پردازش AI ارسال نمی‌کند.
- ارسال گزارش به شهرداری، نظام مهندسی یا کارفرما خودکار نیست.
- ویدئو در PDF به‌صورت مشخصات و هش فهرست می‌شود؛ خود ویدئو داخل PDF قرار نمی‌گیرد.

## توسعه و اعتبارسنجی

پروژه وابستگی زمان اجرا ندارد و با فایل‌های استاتیک اجرا می‌شود. برای کنترل قرارداد انتشار:

```bash
cd mohandesyar-ai
npm run verify
```

گردش‌کار `Verify MohandesYar AI PWA` صحت JavaScript، manifest، مسیرهای عمومی، RTL، اتصال گزارش پویا و جداسازی cacheها را کنترل می‌کند.

آزمون مرورگری انتشار نیز ماندگاری شش تصویر و یک ویدئو، GPS، پشتیبان‌گیری و بازیابی، PDF فارسی چندصفحه‌ای، ارتقای Service Worker، حفظ IndexedDB و اجرای مجدد آفلاین را بررسی می‌کند. تنها کنترل‌های نصب روی دستگاه فیزیکی مطابق [چک‌لیست QA](tests/MANUAL-QA.md) دستی هستند.

## ساختار داده

- `projects`: مشخصات پرونده و محتوای گزارش
- `evidence`: Blob فایل، مشخصات، SHA-256 و GPS اختیاری
- `meta`: شناسه پرونده فعال و وضعیت مهاجرت
