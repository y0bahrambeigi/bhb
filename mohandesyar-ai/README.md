# مهندس‌یار AI

دستیار تخصصی عمران و معماری برای ثبت تحویل زمین، مدیریت پرونده پروژه، نگهداری شواهد میدانی زمان‌دار و تهیه گزارش رسمی قابل چاپ یا ذخیره به‌صورت PDF.

## نسخه آنلاین

[اجرای مهندس‌یار AI](https://mohandesyar-ai.yousefbhb.chatgpt.site)

## امکانات

- تشکیل پرونده پروژه و ثبت مشخصات پایه
- ثبت شواهد میدانی و اطلاعات تحویل زمین
- ساختار ذخیره‌سازی D1 و فایل‌های R2 در محیط Sites
- تولید گزارش رسمی راست‌به‌چپ و خروجی PDF
- رابط واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- PWA قابل نصب روی آیفون، اندروید و رایانه
- کش آفلاین داشبورد، گزارش رسمی و فایل‌های رابط
- نمایش وضعیت اتصال و صفحه جایگزین هنگام قطع اینترنت

## اجرای محلی

### پیش‌نیازها

- Node.js نسخه `22.13.0` یا جدیدتر
- npm
- Linux یا WSL2 در ویندوز

```bash
git clone https://github.com/y0bahrambeigi/bhb.git
cd bhb/mohandesyar-ai
npm ci
npm run dev
```

برای کنترل نسخه تولید:

```bash
npm test
npm run build
npm run start
```

## نصب آفلاین روی آیفون

1. نسخه آنلاین را یک‌بار در Safari باز کنید و منتظر پیام «نسخه آفلاین آماده است» بمانید.
2. دکمه **Share** را بزنید.
3. گزینه **Add to Home Screen** را انتخاب کنید.
4. برنامه را یک‌بار از آیکون صفحه اصلی اجرا کنید.

پس از این مرحله، داشبورد و گزارش‌هایی که قبلاً باز شده‌اند بدون اینترنت نیز در دسترس خواهند بود. عملیات همگام‌سازی سرور، API و بارگذاری ابری شواهد به اتصال اینترنت نیاز دارد.

## چاپ یا ذخیره PDF در آیفون

پرونده فعال را باز کنید، وارد «گزارش رسمی» شوید و کلید «چاپ / ذخیره PDF» را بزنید. در پنجره چاپ، پیش‌نمایش را با حرکت دو انگشت بزرگ کنید و از **Share** گزینه **Save to Files** را انتخاب کنید.

## فایل‌های PWA

- `public/manifest.webmanifest`: مشخصات نصب برنامه
- `public/sw.js`: راهبرد کش و اجرای آفلاین
- `public/offline.html`: صفحه جایگزین قطع اینترنت
- `app/pwa-register.tsx`: ثبت سرویس‌ورکر و نمایش وضعیت اتصال
- `public/app-icon-*`: آیکون‌های نصب موبایل

## حریم خصوصی و محدودیت آفلاین

کش آفلاین فقط برای رابط برنامه و صفحات قابل مشاهده است. مسیرهای `/api/` عمداً کش نمی‌شوند تا پاسخ‌های اداری یا داده‌های پروژه قدیمی و اشتباه نمایش داده نشوند. فایل‌های محیط توسعه، متغیرهای `.env`، خروجی ساخت و داده‌های موقت نیز وارد مخزن نمی‌شوند.

## اعتبارسنجی

دستور `npm test` ساخت Worker، صفحه اصلی، گزارش رسمی، فایل manifest و راهبرد سرویس‌ورکر را بررسی می‌کند.
