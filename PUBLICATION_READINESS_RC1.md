# Publication readiness — RC1

## Ready now
The package is suitable for:
1. a public versioned software release;
2. archival deposition after upload;
3. a methods/software preprint whose claims are limited to architecture, reproducibility, and software verification;
4. a GitHub release with citation metadata.

## Not yet ready for an experimental/performance paper
The following claims remain blocked:
- exact Hu et al. IFD reproduction;
- experimentally validated Rp calculations;
- final real-record Publication-11 seismic performance statistics;
- locked MATLAB BMPOA comparative results using the final source-validated IFD model.

## RC1 verification
The independent Python implementation reproduced the expected 6-story verification frequencies (approximately 1.1510, 3.3862, and 5.4246 Hz) and passed matrix symmetry, positive effective-mass, finite-response, and nonnegative dissipation invariants. Synthetic candidate screening is verification-only and is not earthquake-performance evidence.
