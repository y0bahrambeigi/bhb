# Preprint/software-paper submission checklist

- [x] Title and abstract state a computational-framework contribution.
- [x] Synthetic/provisional results are labeled software verification only.
- [x] Experimental reproduction claims are excluded.
- [x] Independent Python QA executed and archived.
- [x] Source provenance matrix included.
- [x] License and citation metadata included.
- [x] Third-party waveform files excluded from redistribution.
- [ ] Add permanent archive DOI after depositing the tagged release.
- [ ] Confirm exact institutional affiliation wording before journal submission if required.
