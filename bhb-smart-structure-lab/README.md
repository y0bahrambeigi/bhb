# آزمایشگاه سازه هوشمند BHB

وب‌اپ فارسی و تعاملی برای تبدیل تخصص مهندسی سازه، هوش مصنوعی، آموزش و طراحی به یک کسب‌وکار درآمدزا و پایدار.

**تهیه، طراحی و تنظیم: یوسف بهرام‌بیگی**

## نسخه آنلاین

[مشاهده وب‌اپ BHB Smart Structure Lab](https://bhb-smart-structure-lab.yousefbhb.chatgpt.site)

## امکانات

- رابط کاملاً فارسی، راست‌چین و واکنش‌گرا
- پنج مسیر درآمدی تخصصی با فیلتر و انتخاب تعاملی
- برنامه اجرایی ۳۰روزه از ایده تا اولین مشتری
- ذخیره خودکار پیشرفت چک‌لیست روی دستگاه
- پیشنهاد سه اقدام بعدی براساس مسیر انتخاب‌شده
- معماری رشد سه‌مرحله‌ای: خدمت، آموزش و محصول
- فونت‌های فارسی وزیرمتن و لاله‌زار

## اجرای محلی

پیش‌نیاز: Node.js 22 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس نشانی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## ساخت نسخه تولیدی

```bash
npm run build
npm run start
```

## ساختار اصلی

- `app/page.tsx`: محتوا و تعاملات برنامه
- `app/globals.css`: هویت بصری و طراحی واکنش‌گرا
- `app/layout.tsx`: اطلاعات صفحه، زبان فارسی و فونت‌ها
- `public/favicon.svg`: نشان مرورگر

## ملاحظه حرفه‌ای

این برنامه ابزار برنامه‌ریزی کسب‌وکار است. خروجی‌های هوش مصنوعی یا محتوای فنی باید پیش از استفاده حرفه‌ای توسط مهندس مسئول بررسی شوند. فعالیت تجاری شخصی نیز باید از مسئولیت‌های رسمی بازرسی و نظارت مستقل بماند.
