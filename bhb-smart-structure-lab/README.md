# آزمایشگاه سازه هوشمند BHB

مرکز فرمان فارسی و آفلاین برای تبدیل تخصص مهندسی سازه، هوش مصنوعی، آموزش و تولید محتوا به یک کسب‌وکار پایدار.

## نسخه آنلاین

https://bhb-smart-structure-lab.yousefbhb.chatgpt.site

## امکانات نسخه حرفه‌ای ۳.۰

- داشبورد مدیریتی با شاخص‌های درآمد، فروش، مشتری و محتوا
- CRM مهندسی برای ثبت مشتری، مرحله فروش، ارزش فرصت و اقدام بعدی
- دفتر مالی برای درآمد، هزینه، سود خالص و خروجی پشتیبان JSON
- استودیوی محتوا با تقویم انتشار، پرامپت آماده AI و پوستر رسمی ۴:۵
- پنج مسیر درآمدی و نقشه اجرایی ۳۰روزه
- ذخیره‌سازی خصوصی روی دستگاه با localStorage
- نصب PWA و استفاده آفلاین روی Windows، Android، iPhone/iPad، macOS و Linux
- رابط کاملاً RTL با فونت‌های Vazirmatn و Lalezar

## اجرای محلی

نیازمندی: Node.js 22.13 یا جدیدتر.

1. وارد پوشه `bhb-smart-structure-lab` شوید.
2. دستور `npm install` را اجرا کنید.
3. برای توسعه `npm run dev` را اجرا کنید.
4. برای بررسی نسخه تولید `npm run lint` و سپس `npm run build` را اجرا کنید.

## نصب آفلاین

- Windows / macOS / Linux: در Chrome یا Edge گزینه Install را انتخاب کنید.
- Android: در Chrome گزینه Add to Home screen را بزنید.
- iPhone / iPad: در Safari از Share، گزینه Add to Home Screen را انتخاب کنید.

بعد از اولین بارگذاری، پوسته برنامه و داده‌های ثبت‌شده روی همان دستگاه در دسترس می‌مانند. برای انتقال داده‌ها از بخش نسخه آفلاین، فایل پشتیبان JSON دریافت کنید.

## حریم خصوصی

نسخه فعلی بدون حساب کاربری و بدون ارسال اطلاعات CRM یا مالی به سرور کار می‌کند؛ داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند.
