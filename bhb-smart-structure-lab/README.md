# BHB Business OS 3.0

مرکز فرمان حرفه‌ای و فارسی برای تبدیل تخصص مهندسی سازه، هوش مصنوعی، آموزش و تولید محتوا به یک کسب‌وکار پایدار.

## نسخه آنلاین

**https://bhb-smart-structure-lab.yousefbhb.chatgpt.site**

## قابلیت‌ها

- داشبورد مدیریتی با شاخص‌های درآمد، سود، فرصت فروش و محتوا
- CRM مهندسی برای ثبت مشتری، مرحله فروش، ارزش فرصت و اقدام بعدی
- دفتر مالی برای ثبت درآمد و هزینه، محاسبه سود خالص و دریافت نسخه پشتیبان JSON
- استودیوی محتوا با تقویم انتشار، پرامپت آماده هوش مصنوعی و پوستر رسمی ۴:۵
- پنج مسیر درآمدی و نقشه اجرایی ۳۰روزه
- ذخیره‌سازی خصوصی داده‌ها روی دستگاه با `localStorage`
- نصب PWA و کارکرد آفلاین روی Windows، Android، iPhone/iPad، macOS و Linux
- رابط کاملاً RTL با فونت‌های فارسی Vazirmatn و Lalezar
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ

## اجرای پروژه

نیازمندی اصلی: Node.js نسخه `22.13.0` یا جدیدتر.

```bash
npm install
npm run dev
```

سپس برنامه را در آدرس اعلام‌شده توسط Vite باز کنید.

## کنترل کیفیت و ساخت نسخه تولید

```bash
npm run lint
npm run build
```

خروجی معتبر استقرار در پوشه `dist/` ساخته می‌شود. پوشه‌های `node_modules`، `.next`، `dist` و فایل‌های موقت عمداً داخل GitHub قرار نمی‌گیرند و از روی `package-lock.json` بازتولید می‌شوند.

## نصب آفلاین

- **Windows / macOS / Linux:** در Chrome یا Edge گزینه **Install** را انتخاب کنید.
- **Android:** در Chrome گزینه **Add to Home screen** را بزنید.
- **iPhone / iPad:** در Safari، از Share گزینه **Add to Home Screen** را انتخاب کنید.

پس از نخستین بارگذاری، پوسته برنامه و داده‌های ثبت‌شده روی همان دستگاه در دسترس می‌مانند. برای انتقال اطلاعات از بخش «نسخه آفلاین» فایل پشتیبان JSON دریافت کنید.

## ساختار مهم پروژه

```text
app/                 رابط اصلی، منطق CRM، مالی، محتوا و نقشه رشد
public/              آیکون، manifest، service worker و پوستر رسمی
scripts/             نصب، ساخت و اعتبارسنجی قابل تکرار
build/               افزونه ساخت برای محیط استقرار
tests/               آزمون فراداده و خروجی رندرشده
db/                  زیرساخت اختیاری دیتابیس
examples/d1/         نمونه اختیاری توسعه دیتابیس
.openai/hosting.json تنظیمات پروژه منتشرشده
```

## حریم خصوصی

نسخه فعلی بدون حساب کاربری کار می‌کند و داده‌های CRM و مالی را به سرور ارسال نمی‌کند؛ اطلاعات در مرورگر همان دستگاه ذخیره می‌شوند.
