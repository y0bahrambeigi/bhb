# Python Learning Studio Ultra v1.0.0

**Release date:** 2026-08-16  
**Creator:** Yousef Bahram Beigi

## Overview

Python Learning Studio Ultra is an interactive Persian-first environment for Python learning, scientific computing, and computational civil engineering.

## Highlights

- Monaco Editor with a VS Code-like coding experience
- Real Python execution in the browser through Pyodide
- NumPy and Matplotlib support
- In-app scientific plots
- Automated exercises and test runner
- Multi-stage quizzes
- XP, Level, and Achievement system
- Civil Engineering Lab with beam deflection, 2D truss stiffness, and SDOF dynamics examples
- Persian text-to-speech learning support
- PWA installation and offline caching
- Cross-platform build workflows for Android, iOS project preparation, Windows, macOS, and Linux
- AI Tutor interface with support for a secure external AI gateway
