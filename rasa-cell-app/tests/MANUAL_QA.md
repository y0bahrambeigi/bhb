# RASA‑Cell release QA

این چک‌لیست شواهد لازم برای انتشار را از محدودیت‌های توزیع جدا می‌کند. نتیجه هر مورد باید با تاریخ، دستگاه/سیستم‌عامل و نسخه مرورگر ثبت شود.

## آزمون‌های لازم

| سکو | سناریو | معیار قبولی |
|---|---|---|
| Web/PWA | بازکردن نسخه آنلاین، انتظار برای وضعیت «آفلاین آماده»، قطع شبکه و Reload | رابط، مدل، فونت‌ها و هر ۹ مرحله بدون درخواست شبکه بارگذاری شوند |
| Android PWA | نصب از Chrome، یک‌بار اجرا، فعال‌کردن Airplane Mode و اجرای مجدد | برنامه از Home Screen اجرا شود و کنترل مراحل کار کند |
| Android debug APK | نصب Artifact، اجرا، بستن، Airplane Mode و اجرای مجدد | برنامه بدون شبکه باز شود؛ این آزمون به‌معنای آمادگی Play Store نیست |
| Windows Setup | نصب EXE، اجرا بدون شبکه و Uninstall | برنامه اجرا شود و Setup با فایل portable اشتباه یا بازنویسی نشده باشد |
| Windows portable ZIP | استخراج ZIP و اجرای `RASA Cell.exe` بدون شبکه | اجرا بدون نصب و بدون وابستگی شبکه موفق باشد |
| iOS Simulator | نصب ZIP تولیدشده، Launch و مشاهده رابط | Bundle با شناسه `ir.ybb.rasacell` اجرا شود؛ CI این مورد را خودکار کنترل می‌کند |
| iPhone/iPad PWA | Safari → Add to Home Screen → یک‌بار اجرای آنلاین → بستن → Airplane Mode → اجرای مجدد | برنامه از Home Screen و بدون شبکه اجرا شود |

## خارج از دامنه این PR

- Artifact فعلی iOS با SDK مربوط به Simulator و بدون امضای Apple ساخته می‌شود و روی آیفون واقعی قابل نصب نیست.
- تولید IPA برای دستگاه واقعی یا App Store به App ID، گواهی توزیع، Provisioning Profile و گردش `iphoneos archive/export` جداگانه نیاز دارد.
- نبود IPA امضاشده در این PR، نقص PWA یا مدل سه‌بعدی محسوب نمی‌شود.

## تصمیم انتشار

PR فقط زمانی از Draft خارج شود که CI روی آخرین `main` سبز باشد، موجودی Artifactها دقیقاً مطابق جدول باشد و نتایج آزمون‌های دستگاه واقعی Web/PWA، Android و iPhone/iPad ثبت شده باشند.
