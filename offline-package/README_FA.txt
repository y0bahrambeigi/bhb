مدرس و طراح دوره: یوسف بهرام بیگی
نسخه: 2.0.0 — مرداد ۱۴۰۵

محتویات بسته
=============
• چهار سطح و ۲۴ درس فعال از مقدماتی تا هوش مصنوعی و بهینه‌سازی
• تمرین‌های تخصصی عمران، تحلیل داده، ارتعاش سازه و بهینه‌سازی خرپا
• موتور واقعی Python 3 مبتنی بر Pyodide؛ تمام فایل‌های اجرایی داخل بسته است
• آزمون تعیین سطح، ویرایشگر کد، راهنمای تمرین و ذخیره پیشرفت روی دستگاه
• بدون نیاز به حساب کاربری و بدون ارسال داده به اینترنت هنگام استفاده از ZIP

Windows 10 / 11
===============
۱. فایل ZIP را با گزینه Extract All استخراج کنید.
۲. روی START_WINDOWS.bat دوبار کلیک کنید.
۳. مرورگر به‌طور خودکار باز می‌شود. پنجره راه‌انداز را تا پایان آموزش نبندید.
راه‌انداز Windows از PowerShell داخلی سیستم استفاده می‌کند و به نصب Python نیاز ندارد.

macOS
=====
۱. فایل ZIP را استخراج کنید.
۲. روی START_MAC.command کلیک راست و Open را انتخاب کنید.
۳. اگر اجازه اجرا داده نشد، در Terminal و داخل پوشه بسته اجرا کنید:
   chmod +x START_MAC.command
۴. راه‌انداز به Python 3 نیاز دارد. اگر Python موجود نیست، نسخه PWA را طبق بخش موبایل/مرورگر نصب کنید.

Linux
=====
۱. بسته را استخراج کنید.
۲. در Terminal وارد پوشه بسته شوید و اجرا کنید:
   chmod +x START_LINUX.sh
   ./START_LINUX.sh
۳. Python 3 باید روی سیستم نصب باشد.

Android
=======
۱. یک‌بار در حالت آنلاین، نشانی زیر را با Chrome باز کنید:
   https://y0bahrambeigi.github.io/bhb/
۲. از منوی مرورگر Install app یا Add to Home screen را بزنید.
۳. منتظر بمانید عبارت «آماده آفلاین» نمایش داده شود؛ سپس اینترنت را قطع و برنامه را آزمایش کنید.
برای اجرای مستقیم ZIP در Android می‌توان از یک Local HTTP Server استفاده کرد، اما نصب PWA پایدارتر است.

iPhone / iPad
==============
۱. یک‌بار نشانی بالا را با Safari باز کنید.
۲. Share و سپس Add to Home Screen را بزنید.
۳. برنامه را یک‌بار از آیکون صفحه اصلی باز کنید تا موتور Python ذخیره شود.
۴. پس از نمایش «آماده آفلاین»، برنامه بدون اینترنت قابل استفاده است.
به‌دلیل محدودیت امنیتی iOS، نصب مستقیم از ZIP یا IPA بدون امضای Apple امکان‌پذیر نیست.

مرورگرها و Chromebook
=====================
نشانی رسمی را در Chrome یا Edge باز کنید و Install app را بزنید. پس از تکمیل ذخیره اولیه، دوره بدون اینترنت کار می‌کند.

نکات مهم
=========
• پیشرفت هر مرورگر فقط روی همان دستگاه ذخیره می‌شود.
• فایل index.html را با file:// باز نکنید؛ اجرای WebAssembly نیازمند وب‌سرور محلی است.
• در رایانه از راه‌انداز مخصوص سیستم‌عامل استفاده کنید.
• برای خروج از نسخه پرتابل، پنجره راه‌انداز را ببندید یا Ctrl+C بزنید.
• فایل FILE_CHECKSUMS.sha256 برای کنترل سلامت تمام فایل‌های بسته است.
