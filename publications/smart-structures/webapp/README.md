# وب‌اپ تعاملی کتاب سازه‌های هوشمند

نسخه وب و PWA مستقل کتاب «سازه‌های هوشمند و کنترل پاسخ لرزه‌ای» اثر یوسف بهرام بیگی، بر پایه پیش‌نویس توسعه‌یافته ۴۰ صفحه‌ای.

## قابلیت‌ها

- متن کامل ۱۰ فصل، سه پیوست، کتاب‌نامه، جدول‌ها و شکل‌های کتاب؛
- جست‌وجوی فارسی، فهرست فصل‌ها، تغییر اندازه متن، حالت روشن/تیره و ذخیره پیشرفت مطالعه؛
- چهار ابزار تعاملی برای پاسخ فرکانسی SDOF، جداسازی پایه، میراگر ویسکوز و پاسخ تشدید؛
- مقایسه تعاملی نتایج Uncontrolled، Passive و LQR؛
- نصب PWA و استفاده آفلاین در Safari روی iPhone/iPad و Chrome روی Android؛
- رابط RTL واکنش‌گرا، ناحیه امن iOS و کنترل‌های لمسی مناسب موبایل؛
- بدون رهگیری، حساب کاربری یا ارسال داده‌های مطالعه به سرور.

## اجرای محلی

این برنامه به فرایند build وابسته نیست و باید از یک HTTP server اجرا شود:

```bash
python3 -m http.server 4173 --directory publications/smart-structures/webapp
```

سپس `http://localhost:4173` را باز کنید. Service Worker فقط روی HTTPS یا localhost فعال می‌شود.

## کنترل کیفیت

از ریشه مخزن اجرا کنید:

```bash
node publications/smart-structures/webapp/tests/validate.mjs
```

پس از ادغام در شاخه‌ای که GitHub Pages از آن منتشر می‌شود، مسیر مورد انتظار برنامه چنین است:

`https://y0bahrambeigi.github.io/bhb/publications/smart-structures/webapp/`

## مرز کاربرد

محاسبات برنامه آموزشی‌اند و جایگزین ضوابط لازم‌الاجرا، تحلیل پروژه، آزمایش تجهیزات یا قضاوت مهندسی نیستند.
