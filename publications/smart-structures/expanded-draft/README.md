# نسخهٔ توسعه‌یافتهٔ کتاب — مبنای محتوایی v1.0.0

این پوشه نسخهٔ ۴۰صفحه‌ای توسعه‌یافتهٔ «سازه‌های هوشمند و کنترل پاسخ لرزه‌ای» اثر Yousef Bahrambeigi — یوسف بهرام بیگی را نگه می‌دارد. پیوست B شامل مثال عددی Uncontrolled، Passive و LQR و نمونه‌کد MATLAB است.

## وضعیت

این پیش‌نویس مبنای محتوایی نسخهٔ نهایی دیجیتال `v1.0.0` بوده است. نسخهٔ نهایی در ۸ اکتبر ۲۰۲۶ با DOI `10.6084/m9.figshare.34063335.v2` منتشر شد. فایل‌های این پوشه خودشان رکورد DOI مستقل نیستند؛ دارایی‌های frozen نهایی در GitHub Release `smart-structures-v1.0.0` قرار دارند.

## شواهد و محدودیت‌ها

- پیوست B شامل پارامترهای مدل، مقایسهٔ عددی، چهار شکل، کد MATLAB و چک‌لیست است.
- PDF منبع توسعه‌یافته ۴۰ صفحه و Tagged است.
- محاسبات پیش‌نویس با معادل Python/SciPy اجرا شده‌اند؛ اجرای مستقیم نمونه‌کد در MATLAB یا Octave در چرخهٔ نهایی دوباره تأیید نشده است.
- تحریک ورودی مصنوعی و مثال آموزشی است و نتیجهٔ آن تأیید طراحی سازه یا عملکرد عمومی LQR نیست.
- نسخهٔ نهایی DOCX با شش فایل فونت فارسی جاسازی‌شده بازتولید شد؛ این ویژگی نباید به فایل DOCX خام همین پوشه تعمیم داده شود.
- نسخهٔ چاپی و PDF/X خارج از دامنهٔ انتشار دیجیتال v1.0.0 هستند.
