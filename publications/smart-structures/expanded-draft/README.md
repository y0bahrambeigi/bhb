# نسخهٔ توسعه‌یافتهٔ کتاب — پیش‌نویس ۲۰۲۶-۰۹-۰۱

نسخهٔ ۴۰صفحه‌ای «سازه‌های هوشمند و کنترل پاسخ لرزه‌ای» اثر Yousef Bahrambeigi — یوسف بهرام بیگی، با توسعهٔ پیوست B: مثال عددی Uncontrolled، Passive و LQR و کد MATLAB.

## فایل‌ها

- [PDF مطالعه](Smart_Structures_Yousef_Bahram_Beigi_Expanded.pdf)
- [منبع Word](Smart_Structures_Yousef_Bahram_Beigi_Expanded.docx)
- [SHA256SUMS](SHA256SUMS)

این فایل‌ها نسخهٔ توسعه‌یافتهٔ محتوایی هستند و جایگزین خودکار بستهٔ ۳۶صفحه‌ای RC1 و گزارش QA آن نیستند. فایل‌های RC1 بدون تغییر حفظ شده‌اند.

## شواهد و محدودیت‌ها

- پیوست B شامل پارامترهای مدل، مقایسهٔ عددی، چهار شکل، کد MATLAB و چک‌لیست است.
- خروجی ۴۰صفحه‌ای رندر و از نظر چیدمان بازبینی شده است.
- محاسبات با معادل Python/SciPy اجرا شده‌اند؛ اجرای کد در MATLAB یا Octave هنوز تأیید نشده است.
- تحریک ورودی مصنوعی و مثال آموزشی است؛ نتایج، تأیید طراحی سازه یا عملکرد عمومی LQR نیستند.
- گزارش QA فونت، Tagged PDF، زبان، بوکمارک و دسترس‌پذیری RC1 نباید به این فایل‌های جدید تعمیم داده شود.
- PDF حاضر فایل مطالعه/بازبینی است؛ انطباق PDF/X-4 و آمادگی تولید چاپی برای آن ادعا نمی‌شود.
- DOI این کتاب هنوز تأیید و ثبت نشده؛ DOI پروژه‌های دیگر یا ISBN کتاب مرجع نباید برای این اثر استفاده شود.
