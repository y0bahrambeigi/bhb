# سازه‌های هوشمند و کنترل پاسخ لرزه‌ای

این پوشه بستهٔ انتشار نامزد `v1.0.0-rc1` کتاب فارسی «سازه‌های هوشمند و کنترل پاسخ لرزه‌ای» اثر یوسف بهرام بیگی است. RC1 در تاریخ ۳ اکتبر ۲۰۲۶ به‌صورت عمومی در GitHub Releases منتشر شده است.

## وضعیت انتشار عمومی

- GitHub Release عمومی: `smart-structures-v1.0.0-rc1` — منتشرشده و غیر Draft؛
- دارایی‌های Release: DOCX منبع، PDF دیجیتال، `SHA256SUMS`، `CITATION.cff`، `CITATION.bib` و `LICENSE.md`؛
- گردش‌کار انتشار RC1 شامل کنترل checksum و آزمون وب‌اپ با موفقیت اجرا شده است؛
- GitHub Pages برای وب‌اپ پس از انتشار با موفقیت deploy شده است؛
- RC1 در Figshare با DOI آرشیوی `10.6084/m9.figshare.34063335.v1` منتشر و از طریق DOI.org تأیید شده است؛
- آرشیو Zenodo همچنان اختیاری است، اما `ZENODO_TOKEN` در secrets مخزن پیکربندی نشده است؛
- نسخه نهایی `v1.0.0` تا همگام‌سازی فرادادهٔ نهایی در خود دارایی‌ها، اجرای QA نهایی و ایجاد رکورد/نسخهٔ DOIدار نهایی عمداً منتشر نمی‌شود.

## وب‌اپ تعاملی

نسخه مستقل PWA در پوشه [`webapp`](webapp/) بر پایه پیش‌نویس توسعه‌یافته ۴۰ صفحه‌ای ساخته شده است. این نسخه متن کامل، جست‌وجوی فارسی، حالت مطالعه، چهار محاسبه تعاملی، مقایسه Uncontrolled/Passive/LQR، نصب روی iPhone و Android و استفاده آفلاین را فراهم می‌کند. کنترل کیفیت آن با گردش‌کار `Smart Structures webapp` انجام می‌شود.

## نسخهٔ توسعه‌یافتهٔ ۴۰صفحه‌ای

نسخهٔ جدید شامل مثال عددی Uncontrolled / Passive / LQR و کد MATLAB در [expanded-draft](expanded-draft/README.md) قرار دارد. این پیش‌نویس مستقل از بستهٔ RC1 زیر است؛ وضعیت QA، DOI و چاپ آن در راهنمای خودش ثبت شده است.

## مسیر انتشار نهایی

مسیر انتشار `v1.0.0` بر اساس تصمیم مؤلف، **دیجیتال و دارای DOI** است. نسخه چاپی در دامنه این انتشار نیست و الزامات چاپخانه مانع انتشار دیجیتال محسوب نمی‌شوند.

RC1 اکنون منتشر شده است. گیت باقی‌مانده برای نسخه نهایی:

1. درج فرادادهٔ نسخه نهایی و DOI نهایی در خود DOCX/PDF و فایل‌های citation؛
2. اجرای مجدد QA وب‌اپ و کنترل خروجی‌های دیجیتال نهایی؛
3. بازتولید checksumها از دارایی‌های frozen نهایی؛
4. ایجاد نسخه/رکورد DOIدار نهایی (ترجیحاً نسخه جدید از همین رکورد Figshare یا یک رکورد Zenodo مستقل در صورت فعال‌شدن دسترسی)؛
5. ایجاد tag نهایی `smart-structures-v1.0.0` و GitHub Release نهایی.

تا پیش از تکمیل این پنج گام، RC1 مرجع عمومی فعلی پروژه است و نباید به‌عنوان نسخه نهایی DOIدار معرفی شود.

## گزارش QA نامزد انتشار

- DOCX در ۳۶ صفحه بازتولید شد؛ شش فایل فونت Shabnam، Sahel و Vazirmatn جاسازی و رمزگشایی آن‌ها بررسی شد.
- برای هر ۸۵ ردیف جدول `cantSplit` ثبت شده و ۸ جدول داده، ردیف سرستون تکرارشونده دارند؛ ۲۵ جدول تک‌سلولیِ معادله/کادر عمداً سرستون داده ندارند.
- فایل منبع Track Changes ندارد و آزمون ZIP/OOXML آن بدون خطا است.
- PDF دیجیتال نسخهٔ 1.7، Tagged، دارای `/Lang=fa-IR` و زبان XMP برابر `fa-IR` است؛ ۳۱ بوکمارک، ۱۰ پیوند فعال و متن جایگزین برای هر ۸ شکل دارد.
- هر ۲۳ زیرمجموعهٔ فونت در هر دو PDF کاملاً جاسازی شده‌اند و Ghostscript هر دو فایل را بدون خطای نحوی پردازش کرده است.
- رندر هر ۳۶ صفحهٔ DOCX و دو PDF بررسی شد؛ رستر دو PDF با خروجی مرجع DOCX اختلاف پیکسلی ندارد.
- این QA ادعای انطباق رسمی PDF/UA ایجاد نمی‌کند. PDF/X برای انتشار دیجیتال لازم نیست و فقط در صورت تصمیم آینده برای چاپ بررسی خواهد شد.

## بازتولید

اسکریپت `tools/update_publication_docx.py` اصلاحات محتوا، فراداده، قواعد جدول و جاسازی فونت را روی فایل منبع قدیمی اعمال می‌کند. برای انتشار نهایی، مقدار واقعی شناسه با گزینهٔ `--identifier` به آن داده می‌شود. اسکریپت `tools/prepare_publication_pdfs.py` خروجی Tagged PDF تولیدشده از DOCX را بدون تغییر محتوای صفحات بسته‌بندی و زبان/XMP را اصلاح می‌کند.

نسخه‌های دقیق فونت‌های مورد استفاده و مجوزهایشان در `FONT_LICENSES.md` ثبت شده‌اند. [PRINT_SPEC.md](PRINT_SPEC.md) فقط سابقه و الزامات احتمالی یک نسخه چاپی آینده را ثبت می‌کند و جزو گیت انتشار دیجیتال نیست.
