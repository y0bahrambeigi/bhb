# سازه‌های هوشمند و کنترل پاسخ لرزه‌ای

این پوشه بستهٔ انتشار نامزد `v1.0.0-rc1` کتاب فارسی «سازه‌های هوشمند و کنترل پاسخ لرزه‌ای» اثر یوسف بهرام بیگی است.

## تصمیم ادغام

این بسته برای ادغام به‌عنوان انتشار نهایی `v1.0.0` کامل نیست و PR باید Draft بماند. دو ورودی انتشار هنوز موجود نیست:

1. مقدار دقیق DOI یا ISBN و نام ناشر برای درج یکسان در کتاب، `CITATION.bib`، `CITATION.cff`، README و رکورد انتشار؛
2. مشخصات مکتوب چاپخانه شامل قطع نهایی، bleed، نوع صحافی و کاغذ/جلد، پروفایل ICC یا output condition، سقف پوشش مرکب و الزامات علائم چاپ.

اگر هدف صرفاً ادغام زیرساخت و نامزد انتشار باشد، عنوان مناسب squash-merge چنین است:

`Prepare Smart Structures v1.0.0 release candidate (#12)`

عنوان نهایی `Publish Smart Structures book v1.0.0 (#12)` فقط پس از رفع هر دو مانع بالا و اعتبارسنجی PDF/X-4 مجاز است.

## گزارش QA نامزد انتشار

- DOCX در ۳۶ صفحه بازتولید شد؛ شش فایل فونت Shabnam، Sahel و Vazirmatn جاسازی و رمزگشایی آن‌ها بررسی شد.
- برای هر ۸۵ ردیف جدول `cantSplit` ثبت شده و ۸ جدول داده، ردیف سرستون تکرارشونده دارند؛ ۲۵ جدول تک‌سلولیِ معادله/کادر عمداً سرستون داده ندارند.
- فایل منبع Track Changes ندارد و آزمون ZIP/OOXML آن بدون خطا است.
- PDF دیجیتال نسخهٔ 1.7، Tagged، دارای `/Lang=fa-IR` و زبان XMP برابر `fa-IR` است؛ ۳۱ بوکمارک، ۱۰ پیوند فعال و متن جایگزین برای هر ۸ شکل دارد.
- هر ۲۳ زیرمجموعهٔ فونت در هر دو PDF کاملاً جاسازی شده‌اند و Ghostscript هر دو فایل را بدون خطای نحوی پردازش کرده است.
- رندر هر ۳۶ صفحهٔ DOCX و دو PDF بررسی شد؛ رستر دو PDF با خروجی مرجع DOCX اختلاف پیکسلی ندارد.
- این QA ادعای انطباق رسمی PDF/UA یا PDF/X ایجاد نمی‌کند. ترتیب خواندن با فناوری کمکی و آزمون نهایی PDF/X باید در مرحلهٔ انتشار رسمی تکمیل شود.

## استناد

تا پیش از درج شناسهٔ رسمی، از رکورد نامزد انتشار در [CITATION.bib](CITATION.bib) یا [CITATION.cff](CITATION.cff) استفاده کنید. پس از دریافت DOI/ISBN و ناشر، هر دو فایل باید هم‌زمان با صفحهٔ عنوان و رکورد GitHub Release نهایی شوند.

## بازتولید

اسکریپت `tools/update_publication_docx.py` اصلاحات محتوا، فراداده، قواعد جدول و جاسازی فونت را روی فایل منبع قدیمی اعمال می‌کند. برای انتشار نهایی، مقدار واقعی شناسه با گزینهٔ `--identifier` به آن داده می‌شود. اسکریپت `tools/prepare_publication_pdfs.py` خروجی Tagged PDF تولیدشده از DOCX را بدون تغییر محتوای صفحات بسته‌بندی و زبان/XMP را اصلاح می‌کند.

نسخه‌های دقیق فونت‌های مورد استفاده و مجوزهایشان در `FONT_LICENSES.md` ثبت شده‌اند. مشخصات و فرایند لازم برای تبدیل نامزد چاپ به PDF/X-4 نهایی در [PRINT_SPEC.md](PRINT_SPEC.md) آمده است.
